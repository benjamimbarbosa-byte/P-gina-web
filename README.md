Projeto Motos

Este projeto é um site sobre motocicletas, criado para apresentar informações sobre motos de forma simples e organizada.

Arquivos
index.html — estrutura e conteúdo do site.
style.css — aparência e estilos da página.
script.js — funcionalidades e interações.
IMG-20260824-WA0001.jpg — imagem de uma moto.
IMG-20260824-WA0002.jpg — segunda imagem.
VID-20260824-WA0003.mp4 — vídeo sobre motos.
 Tecnologias
HTML
CSS
JavaScript
 Como abrir

Abra o arquivo index.html em qualquer navegador.

Conteúdo

O site fala sobre:

História das motos;
Tipos de motos;
Marcas conhecidas;
Curiosidades;
Importância das motos;
Fotos e vídeos.
Objetivo

O objetivo do projeto é praticar a criação de páginas web usando HTML, CSS e JavaScript.
